# BadUSB payloads

Copy payloads to the Flipper microSD's `badusb` folder using qFlipper. On the Flipper, open **Bad USB**, select a payload, and set the keyboard layout to match the target PC. Connect to a signed-in computer you administer.

[MSConfig Safe Boot](msconfig-safe-boot.txt) is a legacy Windows 10 payload. It changes the next boot to Safe Mode. To undo it, open System Configuration, go to **Boot**, clear **Safe boot**, and restart normally.
