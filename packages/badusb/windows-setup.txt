REM Title:   windows-setup
REM Author:  ponderingBGI
REM Target:  Windows 10/11, signed in at the desktop, online
REM What:    Opens an elevated PowerShell and runs windows-setup/go.ps1 from this repo
REM          (removes OneDrive, debloats, applies settings, installs apps, dotfiles, WSL).
REM Layout:  Set the Flipper's BadUSB keyboard layout to the target PC's layout
REM          (en-US on a fresh US install, de-CH on a Swiss one) or | and : come out wrong.
REM Source:  https://github.com/PonderingAI/flipper-collection/tree/main/windows-setup

REM Give Windows time to enumerate the "keyboard" (first plug-in on a fresh PC is slow)
DELAY 4000

REM Clear any open menu / dialog so Win+R lands on the desktop
ESCAPE
DELAY 300
GUI d
DELAY 700

REM Run dialog
GUI r
DELAY 1200
STRING_DELAY 15 powershell -NoP -Ep Bypass -W Normal -C "irm https://raw.githubusercontent.com/PonderingAI/flipper-collection/main/windows-setup/go.ps1|iex"
DELAY 400

REM Ctrl+Shift+Enter = run as administrator
CTRL-SHIFT ENTER
DELAY 3500

REM UAC: focus starts on "No"; LEFT moves to "Yes" in every language.
REM If UAC is off this just sends a harmless empty line to PowerShell.
LEFT
DELAY 300
ENTER
